### WS-004 —— 一意性を落として、任意の初期値から収束する必要十分条件を ρ(A) < 1 と書いていました

- **どこ** —— trinity-infinity の README（二箇所）、cpsbvbng26-dotcom の作用素の頁（trinity.html の説明と共有カードの文、trinity.js の判定の文）
- **述べていたこと** —— x ← Ax + b が任意の初期値から収束する必要十分条件は ρ(A) < 1
- **何が問題か** —— ρ(A) < 1 が必要十分なのは、任意の初期値から同じ一つの不動点へ収束することです。収束するだけなら、ρ(A) = 1 でも起こります。A = I、b = 0 なら、どの初期値もそのまま動かず、初期値ごとに別の点に留まります。作用素の頁は Q を自由に打ち込めるので、ρ ≥ 1 のときに出していた「収束しない初期値がある」は、この場合に誤りでした。巡回置換の Q と [0,1] の係数に限れば、ρ = 1 になるのはすべての係数が 1 のときだけです。そのときは置換がそのまま回り続けるので、三篇の作用素については短い形でも誤りになりません
- **どうしたか** —— どの箇所も「同じ一つの不動点へ」の形に直しました。作用素の頁の本文の式（任意の初期値から一意の不動点へ収束する ⟺ ρ(A) < 1）と、trinity-operator の README と CITATION.cff は、もとから一意性を書いていました。この登録簿の TI-001 と TI-006 の短い形は、そのときの記録として残します。どちらも一意の不動点への収束を論じた文脈です

### WS-003 —— 存在しないリポジトリを、公開されているものとして記録しました

- **どこ** —— この登録簿の WS-003（初出）、cpsbvbng26-dotcom/README.md と README.en.md の城の縄張り
- **述べていたこと** —— 同じアカウントに `cs50-final-project` という公開リポジトリがあり、README が壊れ、存在しない五ファイルを謳い、旧 DOI が札なしで載っており、LICENSE も CITATION.cff も言語モデル利用の開示も無く、横断検査の視界の外にあります
